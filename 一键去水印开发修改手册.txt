# 一键去水印软件重构开发手册 v2.0

## 1. 问题诊断与重构目标

| 现象 | 根因推断 | 重构策略 |
|------|----------|----------|
| 图片去水印后出现大片马赛克 | 使用传统修复算法（如 `cv2.inpaint`）或简单模糊，无法生成新纹理 | 替换为基于深度学习的生成式图像修复模型（LaMa, MAT, AOT-GAN 等） |
| 视频去水印逐帧马赛克 | 同上，且无帧间一致性处理 | 逐帧修复 + 光流引导的时域平滑后处理 |
| 手动框选去水印依然马赛克 | 手动生成的 mask 直接送入传统修复器 | mask 送入深度学习修复模型，完全替换修复核心 |
| 批量去水印原图直接复制 | 批量处理逻辑错误，未实际调用修复函数或路径混淆 | 重构批量处理管道，严格验证输出与原图的差异 |
| 结果有水印残留或模糊 | 未进行后处理增强或修复区域融合不当 | 增加泊松融合 / 边缘平滑，输出与背景自然融合 |

**最终目标：**  
- 去除水印后区域纹理清晰、与周围内容无缝衔接，人类肉眼无法察觉修改痕迹。  
- 图片、视频均支持一键智能识别水印区域（可选）和手动框选，批量处理结果正确。

## 3. 技术选型与模型

### 3.1 图像修复模型（核心）

**推荐模型：LaMa (Large Mask Inpainting)**  
- 基于快速傅里叶卷积(FFC)，能处理大区域缺失，生成合理纹理。  
- 开源预训练权重丰富，推理速度快，适合产品化。  
- 替代方案：MAT（Mask-Aware Transformer）更注重细节，但略慢；AOT-GAN 在自然场景表现也不错。

**模型获取与集成方式：**
- 使用 PyTorch 加载预训练模型，转换为 ONNX 或使用 torch.jit 进行优化部署。
- 如需要轻量化，可使用 TensorRT 加速。

**重要：** 必须放弃所有基于 `cv2.inpaint` 的调用。

### 3.2 水印检测模型（可选智能模式）

- 可使用 **显著性检测**（如 U²-Net）来定位大面积 logo/文字区域，生成初始 mask。
- 或训练一个小目标检测器（YOLOv8-nano）专门检测常见水印样式。
- 如果仅手动框选，则直接由用户交互产生 mask。

### 3.3 视频一致性增强

- 使用 **RAFT 光流模型** 估计相邻帧运动。
- 对修复后的区域进行光流引导的传播和平均，消除闪烁和帧间不一致。

        tensor = preprocess(image).to(self.device)

### 5.4 核心修复引擎 `core/engine.py`（最重要的部分）

```python
class InpaintingEngine:
    def __init__(self, config):
        self.model = self.load_inpaint_model(config['inpaint_model'])
        self.resolution = config.get('inpaint_resolution', 1024)
        self.device = config['device']

    def load_inpaint_model(self, name):
        if name == 'lama':
            from lama_inpaint import LaMaModel  # 需实现或使用开源
            model = LaMaModel('models/lama_finetuned.pth')
        elif name == 'mat':
            from mat_inpaint import MATModel
            model = MATModel('models/mat.pth')
        else:
            raise ValueError("Unsupported model")
        model.eval().to(self.device)
        return model

    def inpaint_image(self, image: np.ndarray, mask: np.ndarray) -> np.ndarray:
        """
        image: BGR uint8 [0,255]
        mask:  single channel uint8, 255为待修复区域
        returns: 修复后的完整图像 BGR uint8
        """
        # 1. 缩放至模型处理分辨率（保持宽高比）
        orig_h, orig_w = image.shape[:2]
        scale = min(self.resolution / max(orig_h, orig_w), 1.0)
        if scale < 1.0:
            new_w, new_h = int(orig_w*scale), int(orig_h*scale)
            image_resized = cv2.resize(image, (new_w, new_h))
            mask_resized = cv2.resize(mask, (new_w, new_h), interpolation=cv2.INTER_NEAREST)
        else:
            image_resized, mask_resized = image, mask

        # 2. 转换为 Tensor, 归一化
        img_tensor = torch.from_numpy(image_resized).permute(2,0,1).unsqueeze(0).float() / 255.0  # [0,1]
        mask_tensor = torch.from_numpy(mask_resized).unsqueeze(0).unsqueeze(0).float() / 255.0     # [0,1]
        # 将 mask 区域在图像中置为0 (模型输入约定)
        masked_img = img_tensor * (1 - mask_tensor)

        # 3. 推理
        with torch.no_grad():
            inpainted = self.model(masked_img.to(self.device), mask_tensor.to(self.device))
        inpainted = inpainted.cpu().squeeze(0).permute(1,2,0).numpy()  # HWC, [0,1]

        # 4. 缩放回原始尺寸
        if scale < 1.0:
            inpainted = cv2.resize(inpainted, (orig_w, orig_h))
            mask_fullres = cv2.resize(mask_resized, (orig_w, orig_h), interpolation=cv2.INTER_NEAREST)
        else:
            mask_fullres = mask

        # 5. 仅将修复区域替换原图，保留未修改部分绝对不变
        inpainted = (inpainted * 255).astype(np.uint8)
        image = image.astype(np.float32)
        mask_3ch = (mask_fullres > 127).astype(np.float32)[:, :, np.newaxis]
        result = image * (1 - mask_3ch) + inpainted * mask_3ch
        return result.astype(np.uint8)
```

**关键点：**
- 必须保留原图未修复区域像素完全不变（通过 mask 精确替换）。
- 缩放步骤保证模型在恒定分辨率下工作，避免显存溢出。

class PostProcessor:
    def blend(self, original, repaired, mask, method='poisson'):
        """
        使用泊松融合平滑修复边界，消除可见接缝。
        original: 原始图像
        repaired: 修复引擎输出的完整图像（已替换修复区域）
        mask: 单通道，修复区域为255
        """
        if method == 'poisson':
            # 将修复区域中心作为融合中心
            contours, _ = cv2.findContours(mask, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
            if contours:
                x, y, w, h = cv2.boundingRect(contours[0])
                center = (x + w//2, y + h//2)
                # 使用 seamlessClone
                result = cv2.seamlessClone(repaired, original, mask, center, cv2.NORMAL_CLONE)
                return result

### 5.6 视频处理流程

在 `engine.py` 中增加方法：

```python
def inpaint_video(self, video_path, output_path, mask_generator=None):
    cap = cv2.VideoCapture(video_path)
    fps = cap.get(cv2.CAP_PROP_FPS)
    width = int(cap.get(cv2.CAP_PROP_FRAME_WIDTH))
    height = int(cap.get(cv2.CAP_PROP_FRAME_HEIGHT))
    out = cv2.VideoWriter(output_path, cv2.VideoWriter_fourcc(*'mp4v'), fps, (width, height))

    frames = []
    frame_masks = []
    while True:
        ret, frame = cap.read()
        if not ret: break
        if mask_generator:
            mask = mask_generator(frame)
        else:
            mask = self.detector.detect(frame)  # 若无外部生成器，每帧检测
        repaired = self.inpaint_image(frame, mask)
        frames.append(repaired)
        frame_masks.append(mask)

    # 后处理时域一致性
    smoothed_frames = self.post.temporal_smooth(frames, frame_masks)
    for f in smoothed_frames:
        out.write(f)
    cap.release(); out.release()
```

建议视频修复时，第一帧检测水印区域，后续帧利用前一帧 mask 结合光流传播，减少每帧检测计算量，同时保证 mask 稳定。

## 6. 批量处理纠正

在原 `batch_processor.py` 中，必须确保：

```python
def batch_process(input_dir, output_dir, smart_detect=True):
    scheduler = TaskScheduler(config)
    for img_name in os.listdir(input_dir):
        input_path = os.path.join(input_dir, img_name)
        output_path = os.path.join(output_dir, img_name.replace('.jpg', '_clean.jpg'))
        if os.path.exists(output_path):
            continue
        # 关键：必须调用 scheduler 处理
        result = scheduler.process_image(input_path, mask=None, smart_detect=smart_detect)
        # 验证：确保输出图像和原图在某些区域有差异（修复区域）
        if np.array_equal(cv2.imread(input_path), result):
            raise RuntimeError(f"处理失败，输出与原图一致: {img_name}")
        cv2.imwrite(output_path, result)
```

添加差异校验，防止出现“原图复制”问题。

        super().__init__()
        # 根据 lama 官方代码构建网络 (FFC 等)
        self.generator = ...  # 加载架构

    def forward(self, masked_image, mask):

## 1. LaMa 图像修复模型（核心引擎）

  - 用于通用显著性检测：`https://github.com/xuebinqin/U-2-Net/raw/master/saved_models/u2net/u2net.pth`（176.3 MB）

### 代码集成（`core/detector.py`）
```python
import torch
import torch.nn as nn
import torch.nn.functional as F
import numpy as np
import cv2
from torchvision import transforms

# ----- U²-Net 模型定义（从官方仓库复制或直接导入） -----
class U2NET(nn.Module):
    # ... 完整的 U2NET 网络结构 ...
    # 可以直接从 https://github.com/xuebinqin/U-2-Net/blob/master/model/u2net.py 复制
    pass

class WatermarkDetector:
    def __init__(self, model_path='models/u2net.pth', device='cuda'):
        self.device = device
        self.net = U2NET(3, 1)
        self.net.load_state_dict(torch.load(model_path, map_location='cpu'))
        self.net.to(device)
        self.net.eval()
        self.transform = transforms.Compose([
            transforms.ToPILImage(),
            transforms.Resize(320),          # U²-Net 推荐输入尺寸
            transforms.ToTensor(),
            transforms.Normalize(mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225])
        ])

    def detect(self, image: np.ndarray) -> np.ndarray:
        """
        返回单通道掩码 (0-255)，水印区域为 255
        """
        original_h, original_w = image.shape[:2]
        # 预处理
        img_rgb = cv2.cvtColor(image, cv2.COLOR_BGR2RGB)
        input_tensor = self.transform(img_rgb).unsqueeze(0).to(self.device)

        with torch.no_grad():
            d1, _, _, _, _, _, _ = self.net(input_tensor)
            pred = d1[:, 0, :, :]
            pred = torch.sigmoid(pred)
            pred = pred.squeeze().cpu().numpy()

        # 缩放回原始尺寸
        pred = cv2.resize(pred, (original_w, original_h))
        # 二值化
        mask = (pred > 0.5).astype(np.uint8) * 255
        # 形态学闭运算填补孔洞
        kernel = np.ones((5,5), np.uint8)
        mask = cv2.morphologyEx(mask, cv2.MORPH_CLOSE, kernel)
        return mask
```
- **注意**：U²-Net 主要用于前景显著性检测，对于复杂水印可能需要针对性微调。如果你的水印样式固定（如半透明 logo），建议收集一批带有水印的图片，手动标注 mask，然后微调 U²-Net，效果会更准。
